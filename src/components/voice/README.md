# Voice Record UI

应用内录音状态横幅与独立 Tauri 字幕浮窗共用同一个后端 Recording Session。横幅点击返回实际录音所属的 Record，停止并保存后消失；后台补转写进度与重试保留在记录页面。外部浮窗结束录音后先保存，再唤起主窗口定位 Record；打开失败可重试导航，不重复结束。

浮窗展开态的实时转写图标和设置菜单共用权威会话状态。关闭控制实际识别计算，保留原始录音用于结束后补齐。手动偏好与持久自动降级分开；自动降级后必须手动恢复。界面以 session/revision 拒绝旧操作结果，临时字幕不能被迟到推理恢复。折叠、拖动或关闭浮窗不会结束录音。

Record 焦点页保留混合双轨回放和按时间跳转的最终转写。会议纪要默认展开，使用单独的持久化快照；“复制到正文”把当前纪要追加并保存到可编辑正文，后续纪要更新只替换快照。AI 标题随成功的纪要更新，允许覆盖当前标题。

语音设置分别选择识别引擎与文本 AI Profile。跨显示器位置恢复已经进入实现；实时翻译保持暂缓，macOS 集中设备验收和 Windows 完整闭环仍待完成，统一见 `docs/remaining-work.md`。
