# Native presentation operations

These immutable GenOffice operation guides describe the data passed inside `operations[].op` (the surrounding `{op:...,as?}` wrapper is this host adaptation). Read the needed group only. Keep the current native File SourceRef for edits. Media is inline bytes/data only; the worker does not read paths or download URLs.
