# Generated application resources

`agent-host/` is generated by `npm run stage:record-runtime` after preparing the
pinned Node runtime and building the document worker. It contains the executable,
complete Node license notices, utility entry, worker distribution and provenance.
It is bundled under `agent-host/` in the installed application and is not tracked.

The utility process runs with a cleared environment and restricted filesystem
access. It does not fall back to a machine-wide Node installation in release builds.
This resource stage does not declare the separate Pi runtime delivery milestone
complete; provider and platform acceptance remain tracked in GitHub Issues.
