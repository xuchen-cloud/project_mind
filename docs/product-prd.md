# Project Mind Alpha 产品基线

状态：当前正式基线  
更新时间：2026-06-08

## 1. 产品定位

Project Mind Alpha 是一个本地优先、`workspace-first` 的项目整理工作台。

它服务的不是泛笔记，也不是纯任务管理，而是以下连续工作流：

1. 先进入一个真实工作区
2. 在工作区里抓住今天最重要的信息
3. 在QuickNote里持续沉淀项目上下文
4. 在Record里保存更细颗粒度的原始记录
5. 用 Todo、受管文件、引用和 AI 辅助把推进过程串起来

## 2. 当前信息对象

当前产品以以下对象为核心：

- `Workspace`
- `Project`
- `QuickNote`
- `Record`
- `Todo`
- `Todo Progress`
- `Document`
- `File Tag`
- `Contact`
- `AI Artifact`

说明：

- 当前正式主路由不再把 `Activity` 作为一等页面暴露
- 仓库里仍存在部分 Activity 相关代码与测试，但不应视为当前产品主基线

## 3. 当前页面与入口

### 3.1 Workspace Gate

用户启动后先进入 `Workspace Gate`，可执行：

- 打开已有工作区
- 创建新工作区
- 从最近记录重新打开工作区

创建工作区时会：

- 在所选目录内创建 `.project-mind/`
- 初始化 `workspace.json` 与 `workspace.sqlite3`
- 设置工作区密码，用于后续解锁已保存的 AI secrets

### 3.2 Workspace / 工作区

`/workspace` 是当前默认首页，也是工作区级工作区页。

当前包含两种视图：

- `QuickNote`
- `Record`

`QuickNote` 视图当前承载：

- 工作区级 `Daily Brief` AI 总结卡
- 固定单例 `Workspace QuickNote`

`Record` 视图当前承载：

- 工作区记录列表
- 记录搜索
- 新建、编辑、删除工作区记录

页面右侧始终挂载工作区级 `Todo Rail`，用于查看与处理跨项目 Todo。

左侧为工作区侧边栏，提供：

- 项目列表
- 工作区记录列表
- 搜索
- 新建工作区记录入口

### 3.3 项目页

`/projects/:projectId` 是项目主页面，当前同样分为两种视图：

- `QuickNote`
- `Record`

`QuickNote` 视图当前承载：

- 项目名称编辑
- 项目根目录入口
- QuickNote富文本编辑

`Record` 视图当前承载：

- 项目记录搜索
- 标签筛选
- 新建项目记录
- 记录列表浏览与内联编辑

页面左侧挂载项目侧边栏，提供：

- 记录标签页
- 文件标签页
- 搜索与标签筛选
- 文件拖拽导入与受管文件操作

页面右侧挂载项目级 `Todo Rail`。

### 3.4 Record Focus Page

`/projects/:projectId/records/:noteId` 提供单条项目记录的专注编辑页，用于更沉浸地编辑与回看记录内容。

### 3.5 顶栏能力

当前顶栏承载：

- Workspace 入口
- 项目页签
- 新建项目
- Ask
- 全局搜索
- 归档项目入口
- 工作区菜单
- 设置入口

## 4. 当前核心能力

### 4.1 工作区与本地存储

- 支持打开、创建、切换工作区
- 支持最近工作区列表
- 支持打开工作区根目录
- 支持锁定 / 解锁已保存的 AI secrets

### 4.2 项目

- 创建项目
- 编辑项目名称
- 编辑QuickNote
- 打开项目根目录
- 归档与恢复项目
- 在顶栏中以页签方式切换打开中的项目

### 4.3 记录

工作区记录与项目记录当前都支持：

- 富文本正文
- 可选标题
- 自动保存
- 搜索
- 编辑与删除

项目记录额外支持：

- 显式标签编辑器
- `#标签` 从正文自动同步到项目标签字典
- 内部引用 `[[...]]`
- 联系人提及 `@...`
- 记录焦点页跳转

### 4.4 Todo

当前 Todo 能力包括：

- 工作区中按项目创建 Todo
- 项目页中创建项目级 Todo
- 状态切换
- 优先级调整
- 正文内联编辑
- 进展新增、编辑、删除
- 标签同步
- 内部引用与联系人提及

### 4.5 文件

当前受管文件能力包括：

- 项目内导入文件
- 拖拽导入
- 导入前批量打标签
- 打开文件
- 在系统文件管理器中定位
- 重命名
- 标星
- 删除
- 版本管理
- 缺失文件状态标记

### 4.6 标签与联系人

当前提供两类轻量结构化工具：

- 项目标签
- 联系人

用途：

- 标签用于记录、Todo、文件的分类与筛选
- 联系人用于正文与 Todo 中的提及

### 4.7 AI

当前 AI 能力分成三类：

- `Ask`
- `Artifacts`
- `Editor Rewrite / Suggestion Generation`

当前正式暴露的 AI artifact：

- `project_brief`
- `daily_brief`

Ask 当前特征：

- 单轮问答
- 只保留最新一条回答
- 根据当前范围检索本地对象
- 尽量附带可跳转引用

## 5. 当前设置面板

设置面板当前包含 5 个分区：

- `页面宽度`
- `项目标签`
- `联系人`
- `AI 设置`
- `富文本样式`

说明：

- 项目标签是项目级设置
- 其他分区当前按工作区作用

## 6. 当前用户流

### 6.1 首次进入

1. 打开应用
2. 创建或打开工作区
3. 进入 `/workspace`
4. 根据需要创建项目

### 6.2 记录今天的上下文

1. 进入工作区页
2. 在 `Workspace QuickNote` 中记录当日判断、临时结论或提醒
3. 如有需要，将选中文本追加到某个QuickNote

### 6.3 沉淀项目上下文

1. 打开项目
2. 在 `QuickNote` 视图维护QuickNote
3. 通过内部引用、联系人提及与标签组织内容

### 6.4 保存更细颗粒度记录

1. 在项目页切换到 `Record`
2. 新建记录
3. 为记录补标题、标签和正文
4. 需要时进入记录焦点页继续编辑

### 6.5 跟进 Todo

1. 在工作区或项目页创建 Todo
2. 用优先级、进展、标签组织推进状态
3. 通过引用回到对应记录或项目上下文

## 7. 非目标

当前版本不把以下内容作为正式基线：

- 多轮 AI 聊天历史
- 导出为 Markdown 或同步到远端知识库
- 完整多主题系统
- 面向团队协作的多人实时同步
- 以 Activity 为主页面的旧流程继续作为默认入口
