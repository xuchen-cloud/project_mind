## 10 分钟开始使用 Project Mind

第一次使用时，你只需要完成一个小闭环：建立本地 Workspace，创建一个 Project，再把当前上下文分别放进 QuickNote、Record 和 Todo。完成后，你会有一个可以继续推进的真实工作现场。

下面用“智能客服知识库升级”作为示例。你可以直接换成手头正在推进的工作。

### 1. 创建 Workspace

Workspace 是长期存在的工作与知识边界。Project、数据库、设置等内容都会放在你选择的 Workspace 中。

1. 在起始页点击“新建 Workspace”。
2. 在“Workspace 根目录”旁点击“选择”，选一个你会长期保留的本地目录。
3. 设置“Workspace 密码”。这个密码用于加密保存在当前 Workspace 中的 AI API Key。
4. 点击“创建 Workspace”。

Project Mind 会在所选目录中创建 `.project-mind` 隐藏目录，并进入 Workspace 页面。

<!-- SCREENSHOT: getting-started-quick-start-01-create-workspace.png | “新建 Workspace”对话框，已选择脱敏后的根目录并填写 Workspace 密码，突出“创建 Workspace”按钮 -->

> Workspace 不等于某一个 Project。它可以长期承载多个阶段性 Project，也可以保存不属于任何 Project 的内容。

### 2. 创建第一个 Project

Project 是围绕明确结果建立的阶段性工作现场。像“升级智能客服知识库”这样有目标、会推进、也会结束的工作，适合建立 Project。

1. 在 Workspace 左侧栏保持“项目”标签页。
2. 点击“新建项目”。Project Mind 会立即创建一个“未命名项目”，并打开它。
3. 直接输入项目名称，例如“智能客服知识库升级”，然后按 `Enter` 或点击名称以外的位置。

<!-- SCREENSHOT: getting-started-quick-start-02-first-project.png | 新创建的 Project 页面，项目名称输入框已选中，左侧栏显示该 Project -->

### 3. 用 Project QuickNote 写下当前上下文

新 Project 默认打开 `QuickNote` 视图。Project QuickNote 是这个 Project 中唯一的低摩擦缓冲区，适合先记下尚未决定最终形式的背景、判断和候选行动。

1. 确认页面上方选中的是 `QuickNote`。
2. 在主编辑区写下项目目标和眼下最重要的判断，例如：

   ```text
   目标：减少客服重复查找答案的时间。
   当前判断：先整理高频问题，再决定知识库结构。
   ```

3. 输入完成后点击编辑区外，让内容保存。

<!-- SCREENSHOT: getting-started-quick-start-03-project-quicknote.png | “智能客服知识库升级”的 QuickNote 视图，正文包含目标与当前判断 -->

QuickNote 不需要一开始就写得完整。它的作用是先接住当前上下文；当某段内容值得独立查找和引用时，再沉淀为 Record；当它已经是明确行动时，再建立 Todo。

### 4. 沉淀第一条 Project Record

Record 用于保存已经判断值得长期保留、可以独立查找和引用的信息。第一条 Record 可以是一条有完整上下文的调研发现或会议结论。

1. 在左侧项目侧边栏保持“记录”标签页，点击搜索框旁的“新增记录”按钮。
2. 在打开的 Record 专注页输入标题，例如“高频问题初步盘点”。
3. 在正文中写清信息来源、观察和判断，例如“过去一周的咨询主要集中在退款进度与账号登录”。
4. 点击编辑区外，并等待页面显示“已保存”。

<!-- SCREENSHOT: getting-started-quick-start-04-first-record.png | Project Record 专注页，显示标题、简短正文和“已保存”状态 -->

这条内容会成为当前 Project 的 Project Record，不会出现在 Workspace Record 中，也不会改变 QuickNote 的内容。

### 5. 创建第一条 Project Todo

Todo 用于跟踪需要完成的明确行动。为了让第一条 Todo 归属于刚创建的 Project，请在该 Project 的 `Current Project View` 中创建它。

1. 返回 Project 页面，在右侧找到 `Todo List`。
2. 如果当前显示的是 `Workspace View`，点击视图切换按钮进入 `Current Project View`。
3. 点击右上角的“+”按钮。
4. 输入一条可以执行的行动，例如“整理退款进度类问题的标准答案”。
5. 点击“创建”。

<!-- SCREENSHOT: getting-started-quick-start-05-first-project-todo.png | Project 页面右侧 Todo List 的 Current Project View，显示新建 Todo 编辑区和创建后的 Todo -->

现在你已经完成了最短闭环：QuickNote 保留项目当前上下文，Record 保存值得长期回看的信息，Project Todo 跟踪下一步行动。三者都属于“智能客服知识库升级”这个 Project。
