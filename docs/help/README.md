## 适合与不适合

Project Mind 适合个人把持续积累留在 Workspace，把围绕明确结果的阶段性工作放进 Project。你可以先用 QuickNote 捕捉，再把值得保留的信息沉淀为 Record，把需要跟踪的行动建立为 Todo，并让 Project Record、Project Todo 和 File 留在同一个 Project 中。

它当前不适合这些需求：

- 把没有明确终点的长期责任当作 Project；这类内容应留在 Workspace。
- 把 QuickNote 当作不会变化的长期资料库；需要保留时应创建 Record。
- 用 Archive 表示完成或删除；Archive 只让 Project 可逆地退出活跃工作范围。
- 用 Record Export 备份整个 Workspace；它只导出一条 Record。
- 与 AI 多轮聊天、让 AI 浏览整个 Workspace 或自动执行多步操作；AI 编辑只处理你明确选择的文字或单张图片，结果由你决定是否写入正文。
