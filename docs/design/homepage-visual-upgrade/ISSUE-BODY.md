## 已确定的设计

- 主色黑白灰，蓝色少量点缀；封面保留自然颜色。封面与页头合并，底部白色渐变遮罩，身份图标为半透明毛玻璃底座。封面编辑按钮仅悬浮/键盘聚焦时出现。
- Workspace 左上项目列表、左下全部 Workspace Tag，不列具体记录；Project 左上有限最近记录、左下全部 Project Tag。标签与中间 Record 列表联动，作用域隔离。
- 中间合并 QuickNote 与 Record；QuickNote 自动增高至上限后内部滚动、吸顶、自动保存，可展开模态窗。
- 拆分按钮整篇存为新 Record，菜单追加至同作用域 Record；成功后清空本次内容，失败不丢内容，防重复与自动保存竞态。移除 QuickNote 选区转存入口。新记录自动标题/标签，显式 #标签与合适首行优先，AI 失败可兜底。
- Project 右侧上 Todo、下 File，保留 Todo 当前项目/整个工作区切换及现有文件管理能力。
- Workspace 右侧工作区 Todo，底部小尺寸 Nori 胸像和 slogan。身体略向内侧、头正对镜头，大小/位置严格参考图；不新增工作区文件实体或最近项目文件聚合。
- 项目专属图标、内置及自定义上传裁切封面；Record 卡片统一。
