# 统一列表标记与 Todo 置顶（#291）

日期：2026-11-01。关联 [Issue #291](https://github.com/xuchen-cloud/project_mind/issues/291)，基线 `c99f3d6`。依赖 #288 的本机列表置顶、统一右键菜单与滚动区域实现。

## 交付与边界

所有在用的 Workspace / Project 项目、记录、文件和会话列表复用 `ListPinIndicator`：12px、次级文字色、描边小图钉，位于行最右端。修正侧栏通用 SVG 尺寸规则，避免将标记放大至16px。主页记录卡片的标记移出标题及悬浮按钮区；语音身份图标仍留在标题旁。会话运行指示在置顶标记左侧，互不覆盖。

文件保留既有 `isStarred`、标星 API 和排序语义，平铺与目录树统一显示右端标记。平铺文件版本号默认隐藏，hover / focus-within 或版本菜单已展开时显示，保留键盘入口和原版本选择；显示时不挤动标记。目录树原本没有版本号，本包不新增；文件详情及固定历史 Tab 不套用列表隐藏规则。

Todo 新增右键置顶 / 取消置顶。复用 pin store 的 `todos` 范围，按真实 Workspace 根路径保存；同一 Todo 在项目和工作区聚合视图共享，其他 Workspace 的相同数字 ID 隔离。现有归属、完成状态分组保留，组内先置顶、再保留用户当前优先级或时间顺序。置顶不调用业务更新，不改变 priority、status 或 updatedAt。完成/恢复动画及原有菜单继续工作。

非目标：不改数据库、权限、File 标星存储、会话管理接口、Todo 子任务模型，或右侧 Rail 的固定按钮语义。不增加兼容/重试框架。
