# 分诊标签

工程技能使用五种标准分诊角色。本文件把这些角色映射到本仓库议题跟踪器中的实际标签字符串。

| mattpocock/skills 中的标签 | 本仓库跟踪器中的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估此议题 |
| `needs-info` | `needs-info` | 等待报告者提供更多信息 |
| `ready-for-agent` | `ready-for-agent` | 已充分说明，可交由 AFK agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某个角色（例如“应用 AFK-ready 分诊标签”）时，使用表中对应的标签字符串。

如果以后采用不同的标签词汇，可直接编辑右侧一列。
