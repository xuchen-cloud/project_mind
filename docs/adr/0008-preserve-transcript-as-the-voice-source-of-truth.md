# Preserve Transcript as the voice source of truth

A Voice Record continuously persists its original, time-aligned Transcript as read-only source material; polishing, translation, Live Captions, and Meeting Minutes Snapshots are replaceable derived views and never overwrite it. Users edit by copying derived content into the Record body. This requires storing multiple representations, but preserves traceability, recovery, and the ability to rerun later models without accumulating earlier model changes.
