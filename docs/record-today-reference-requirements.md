# Project Mind Alpha 记录 / Today / 引用改动需求文档

## 1. 目的

本次改动聚焦 5 条主线：

- `记录编辑体验升级`
- `项目 / 活动简介富文本化`
- `Today 工作台`
- `Todo / 进展可维护性`
- `结论 / 文件 / 内部引用规则统一`

目标是在现有 `Project / Activity / Note / Conclusion / Todo / Document` 架构上，把“记录 - 沉淀 - 跳转 - 回看”链路补齐。

## 2. 需求范围

### 2.1 记录与编辑器

- 记录新增独立标题输入框，位于正文上方，仅单行展示。
- 标题输入后按 `Tab` 或 `Enter`，焦点直接跳到正文编辑区，不换行。
- 当当前 `Activity` 下没有记录时，点击空态提示文案可直接创建默认记录并进入编辑。
- 记录支持“全页编辑模式”，只作用于记录编辑器。
- 全页编辑模式下：
  - 编辑器占据主内容区
  - 工具栏固定在顶部
  - 正文区域滚动
  - 页面宽度使用更宽默认版心
- 记录编辑器支持选区级 AI 操作，首版支持对选中文本进行润色、改写；无选区时不可执行。
- 顶部切换项目后，再切回项目时，应回到该项目本次会话最近访问的子页面，而不是固定回项目总览。

### 2.2 项目 / 活动简介

- 项目简介从纯文本改为富文本。
- Activity 页面新增独立“活动简介 / 概览”富文本区域，不复用记录本身。
- 项目标题旁新增项目状态标签，展示现有状态值。

### 2.3 Today 工作台

- Today 页面始终可见，不再依赖 AI `daily brief` 开关存在。
- Today 改为综合页，包含：
  - `快记`
  - `Today Todo`
  - `AI 今日概览`
- `快记` 是 workspace 级固定单例文档，始终处于编辑状态，滚动更新，不新建多条文件。
- `Today Todo` 支持直接新增 Todo。
- 在 Today 新增 Todo 时，必须选择归属项目，可选绑定 Activity。
- Today Todo 中：
  - 项目级 Todo 可点击项目入口跳到项目总览
  - 活动级 Todo 保留 Activity 跳转入口
  - Todo 仍支持修改所属 Activity
- `AI 今日概览` 仅在 AI 功能打开时显示，不影响 Today 页整体存在。

### 2.4 Todo 与进展

- Todo 删除保留右键入口，但删除时不再弹确认窗口。
- Todo 进展支持右键菜单进行“修改 / 删除”。
- 进展新增或修改时，若内容为空，则不新增、不保存。
- Todo 当前展示的关联 Activity 支持点击后重新选择，可改绑到同项目下其他 Activity，也可改回项目级。

### 2.5 结论与文件

- 项目页与活动页的结论都支持“置顶”。
- 结论排序统一为：`置顶优先，其余按创建时间倒序`。
- 结论创建 / 编辑区中，保存按钮后增加“置顶”按钮或等价控件。
- 活动级新增结论默认开启“提升到项目首页”，项目级新增结论默认关闭。
- 活动级导入文件默认标星，项目级导入文件默认不标星。
- Activity 页面新增“项目级标星文件”折叠区，默认收起，用于展示当前项目下已标星的项目级文件。

### 2.6 内部引用、粘贴与复制

- `记录 / 结论 / Todo` 统一支持内部引用。
- 输入 `[[` 后唤起统一引用选择器，插入内部引用。
- 引用需保存稳定对象标识，并渲染为可点击跳转的内部链接。
- 点击引用时，沿用现有项目路由和 `focus` 锚点跳转机制。
- 空内容编辑器可直接粘贴图片，不需要先输入字符。
- 剪贴板图片应尽量保留原始清晰度，避免明显降质。
- 从富文本复制到纯文本编辑器时，应去掉异常空符号，并正确保留列表编号等纯文本结构。

### 2.7 侧边导航

- 左侧 Activity 侧边栏增加“新建 Activity”入口。
- 展开态与收起态都需要可触达。
- 项目内切换 Activity、从 Today 跳转、从搜索跳转后，都要更新该项目本次会话的最近访问页面记忆。

## 3. 规则与默认值

- “活动级结论默认标星”在本产品内仍映射为“默认提升到项目首页”。
- 全页编辑模式首期只覆盖记录，不扩展到项目简介、活动简介、结论、Today 快记。
- 页面宽度首期只做“默认加宽”，不做拖拽或多档切换。
- 项目最近访问位置只在当前应用会话内记忆，不要求跨重启恢复。
- 内部引用首期只覆盖 `记录 / 结论 / Todo`，不把普通文件附件纳入统一 `[[引用]]` 范围。

## 4. 验收口径

- 标题输入后按 `Tab / Enter` 可直接进入正文编辑。
- 无记录时点击空态可直接创建默认记录。
- 全页编辑模式下工具栏固定、正文滚动、版心变宽。
- 项目切换后切回，能回到上次访问的 Activity 或锚点位置。
- 项目简介、活动简介都支持富文本编辑与回显。
- Today 页面始终可访问；快记始终只有一份。
- Todo 删除不弹确认；进展支持修改 / 删除；空进展不会落库。
- Todo 可修改所属 Activity。
- 结论在项目页和活动页都支持置顶，排序遵守“置顶优先 + 创建时间倒序”。
- 活动级文件默认标星；Activity 页面可展开查看项目级标星文件。
- `[[` 可插入并跳转内部引用。
- 空编辑器可直接粘贴图片；复制到纯文本时列表编号和文本结构正常。
