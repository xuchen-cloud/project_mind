# HTML 网页在项目标签页中运行

更新：2026-10-23。关联 Issue：[#115](https://github.com/xuchen-cloud/project_mind/issues/115)，父需求 [#118](https://github.com/xuchen-cloud/project_mind/issues/118)。状态：H01–H03 已实现，macOS 原生组件验收通过；Windows 平台和完整产品验收未完成，Issue 保持开放。

## 目标与边界

点击项目 HTML/HTM，在现有项目内容标签页内像普通网页一样运行 HTML、CSS、JavaScript；支持已构建的多文件静态站点、相对资源、CDN、浏览器规则允许的 API 和 HTTP(S) 导航。保留源码、固定主文件版本、刷新、前进/后退、自适应/375/768/1440 视口及外部打开。源码页使用现有完整原文读取，不把执行副本写回 File。

依赖现有 File 注册、resolve/resolveRelated、固定版本/hash 读取、归属和 Workspace generation 校验、项目内容布局与版本恢复。HTML 所在目录是本站点根；URL 根路径、相对路径和子页面均对应该目录，不允许目录列表、隐藏内部目录、上级目录或跨 Project 访问。查询参数不改变资源文件身份。

非目标：自动 npm 安装/构建/启动后端、通用网站代理、浏览器扩展、完整下载管理、放宽 CORS、另建文件/版本仓库。本次执行包不顺带建设 HTML 源码编辑器；原 #115 编辑要求仍保留待办。真实后端必须由网页作者提供。历史依赖原子快照单独交付，当前固定历史 HTML 遇到未保留的依赖显示错误，不混入最新资源。

## 运行与隔离契约

1. 主应用 React 工具栏与网页执行环境分离。复用锁定的 Wry 原生子 WebView，以主线程调度在现有窗口的内容区域创建；无独立产品窗口。不给网页注册 Tauri IPC、asset/tauri/app 自定义协议或应用初始化脚本，不传 Workspace 路径、模型凭据和数据库对象。网页错误诊断通道只允许有界文本，不能触发应用命令。
2. 每个执行会话独立随机本机端口与临时浏览数据；HTTP 仅监听 127.0.0.1。初始秘密入口建立 HttpOnly/SameSite 会话认证，随后使用正常站点路径；检查 Host/Origin，拒绝跨站取本地资源，不提供 CORS 开放头。秘密入口不通过 Referer 外发。
3. HTTP 服务只读已授权站点资源，复用原生 File 归属/固定版本读取与路径保护；不接受任意文件系统绝对路径。拒绝路径穿越、双重编码穿越、盘符、UNC、反斜线、NTFS ADS 及符号链接/junction 逃逸。对请求/缓存/诊断设置明确预算，失败如实显示。
4. 主 HTML 校验完整版本/hash 后才执行，保留原始 JS/CSS，不经过静态 sanitizer。当前资源按同 Project 站点根解析；固定历史没有依赖快照则返回缺失，不静默读当前资源。每次资源读取校验 Workspace binding 和根 File 身份，变更需刷新。
5. 允许网页正常联网、HTTP(S) 导航和网络表单；遵循引擎 CORS/HTTPS/权限规则，不额外授予本机能力。禁止 file/asset/tauri/ipc 等特权协议导航，不注册可读取本机的资源协议。新窗口链接在当前网页视图导航；下载管理暂不支持并明确提示。
6. 刷新与切换主 File 版本销毁旧执行会话，建立新会话；普通标签隐藏保留页面状态并隐藏子视图。源码模式、关闭、主页面重载、Workspace 切换和父窗口销毁停止服务并释放子视图。过期异步创建结果立即销毁，不复活已关闭的页面。
7. 原生子视图不得盖住标签栏/其他面板/菜单/对话框；容器 resize、分栏、拖动、窗口尺寸、系统 DPI 和页面缩放后更新边界。DOM 浮层覆盖时隐藏对应原生视图，关闭后恢复。

## Windows 验收要点

- WebView2 在异步 Tauri command 中请求主线程创建，不能同步阻塞 UI 线程；使用独立临时浏览数据目录，确认不会继承主应用会话与存储。
- 边界使用容器坐标和宿主物理尺寸转换，验证 100%/125%/150%/200% DPI、跨屏、缩放、最大化、窄窗口、双栏与标签拖移；原生视图不得遮住 DOM 菜单/对话框。
- URL 使用正斜线与 UTF-8 百分号编码；真实中文、空格、盘符、UNC、反斜线、ADS、大小写及 junction 场景分别验证。
- 验证 WebView2 缺失/初始化失败时错误可见，旧视图和 HTTP 监听不残留；关闭后释放 profile/句柄，不妨碍项目文件改名/删除。
- 本机无 Windows 运行环境时可完成可移植测试与交叉编译检查，但不能以此标记 Windows GUI/安装验收通过。
