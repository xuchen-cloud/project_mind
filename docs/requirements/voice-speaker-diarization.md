# Voice Record：录音后的本地说话人区分

## 工作包

- 关联 Issue：[#234](https://github.com/xuchen-cloud/project_mind/issues/234)；延续 #94 的 Voice Record，取代首版 D-03.7 不区分说话人的范围限制。
- 依赖：现有双原始 Voice Source Track、已结束 Recording Session、sherpa-onnx 1.13.8；额外准备经固定 SHA-256 校验的说话人模型。
- 交付行为：本地识别录音结束后自动排队，在本机分析已保存音频；已有录音可手动开始；显示会话内“说话人 1、2…”及发言时间段，允许命名或关联已有 Contact；用户确认声音后在本 Workspace 本地记住声纹，后续录音自动匹配该 Contact。
- 非目标：实时说话人字幕、跨 Workspace 共享声纹、未经用户确认建立姓名/声纹映射、逐词归属、多人重叠语音分离、更换 ASR 或重写 Transcript。

## 行为与数据约束

1. 说话人标注是独立的派生结果，保留 Transcript 原文、时间戳与原始音频。只根据音频区分声音，姓名来自用户输入。
2. 说话人模型与本地 ASR 分开准备。模型就绪后，本地 ASR 会话在明确结束并保存后自动入队；其他或历史录音可在转写区域手动分析。缺少模型时引导设置页一键准备，不影响录音或已有转写。
3. 在整场录音内聚类，并按首次出现固定说话人编号。两路声音依照 epoch 内原始时间同步混合，暂停/继续的 epoch 累积映射到已有播放时间轴。
4. 标注状态为 not_started、pending、running、ready、failed。失败保留明确错误并允许手动重试；已完成结果不自动重跑，以保留用户命名。重复请求不重复创建任务。
5. 后台最多执行一个说话人分析；录音优先。开始录音、切换或关闭 Workspace 时取消或暂停处理，推理后的提交再次核实会话、当前 Workspace 与任务版本。崩溃残留任务在重新打开后可恢复。
6. 结果与命名属于单个 Recording Session。命名 trim 后为 1～80 字符，使用 revision CAS，过期保存不能覆盖较新命名；Record/Session 删除时附属数据级联清理。
7. 转写片段按时间相交显示对应的说话人，可能显示多个名字；无匹配则显示“未确定”。不以文字上下文猜测身份，不在跨说话人的一句内假造逐词归属。
8. 首版分析上限为两小时有效录音，源文件读取与推理有明确资源预算；超限显示实际错误，不静默只处理前半场。
9. Contact 复用现有 Workspace 联系人能力。用户显式“确认并记住声音”才写入联系人声纹；只有自动匹配不更新声纹，避免误认结果反过来训练。声音样本不足三秒干净连续语音时只关联本次录音。
10. 声纹来自同一固定模型，最多使用每人三十秒非重叠语音片段；只与同 Workspace、同模型版本的已确认联系人声纹比较。初始匹配门槛为 cosine ≥ 0.65 且领先其他联系人 ≥ 0.1；同场多人竞争同一联系人时也须明显领先，否则匿名。聚类采用上游针对本模型的 0.9 阈值，不预设人数。两者用途不同；此门槛不是会议域误识率保证。
11. 自动结果标注“自动匹配”，允许确认、改选或解除关联；手动重命名解除该说话人的联系人关联。解除或纠正时撤销由本次说话人写入的旧声纹。联系人改名动态反映在标注，删除联系人时清理其声纹；删除源录音保留用户已确认的联系人声纹，供后续录音复用。

## 验收与验证范围

- 真实官方四人中文音频：不预先提供人数，执行固定 ONNX 模型得到四个稳定编号与有效时间段；用同人不重叠片段实际确认联系人后，在后续会话自动匹配，异人片段保持匿名。
- 引擎：两路混合、分片及暂停/继续时间轴、音频格式、取消与预算、模型校验失败。
- 持久化：结束前拒绝、作用域隔离、幂等排队、任务 CAS、恢复、命名并发及重开持久化、删除清理、Transcript 不变。
- 联系人：确认才学习、下一场自动关联、自动结果不学习、未知/歧义/同场竞争拒绝匹配、样本不足只关联、改名/删除、不同 Workspace 隔离、解除与纠正。
- 界面：导入与错误状态、自动进度、手动开始/重试、说话人命名和转写标签联动、多说话人/未确定展示。
- 收口：相关 Voice Rust/前端测试、TypeScript/前端构建和受影响静态检查，主 agent 自行完成 Standards / Spec 双轴 review；已通过的检查按未变范围复用。
- 产品验收：集中执行界面检查并提前告知；真实会议准确率与 macOS 实机性能未验证时明确记录，不将官方样例当成这些验收的替代。

## 首次配置简化（#237）

关联 [#237](https://github.com/xuchen-cloud/project_mind/issues/237)，依赖 #234 已有的固定模型包校验与原子激活。用户保留事后说话人识别，不新增实时说话人或文字复核。

- 设置页提供一个“下载并启用”按钮，由应用准备两个模型及随附许可，共约 46 MB。主界面不要求用户理解模型文件、SHA-256、解压或重命名；现有本地 ASR 模型不重复下载。
- 使用固定官方 HTTPS 文件与 revision，流式写临时目录，显示真实字节进度，全部校验成功后激活；保留 TLS 和系统代理，不发送用户音频。已有就绪包直接复用。
- 单进程只执行一个安装任务。关闭并重新打开设置可以读取当前进度；完成后刷新设置与录音页的共享状态。失败展示原因并允许用户重试，不自动循环重试。
- 原有文件夹离线导入保留在“高级选项”。本包不扩展 ASR 下载、通用资源管理、断点续传或外部模型选择。
- 验证范围：真实 loopback HTTP 下载/进度、错误或校验失败不激活、旧缓存保护、已就绪包复用、并发去重与手动重试；前端安装状态/关闭重开/查询失效/离线入口；类型与生产构建、UI 标准、集中界面验收及主 agent Standards / Spec 自查。
