## 包 1：录音可靠性

对应：VR-07、VR-17 的相关子项。

- [ ] **滚动分片**：持续录音按时长或大小切换文件；原始双轨保留统一时间轴；活动文件与已完成清单可恢复；播放与跨分片 seek 连续。
- [ ] **磁盘异常**：开始前检查可写性和可用空间；录制中写入失败或空间不足及时暂停双路、显示原因，保留此前有效分片。
- [ ] **退出保存**：主窗口退出、系统菜单退出、更新重启走统一“结束并保存 / 取消”流程；关闭或切换 Workspace 守住保存边界；网络请求不能无限阻塞退出。
- [ ] **删除清理**：录制中保护目标 Record；结束后删除 Record / Project 时按受管清单清理音频和派生数据，清理失败可重试；迟到回调不能重建已删除记录。

验收：连续录音跨分片、分片边界 seek、写盘失败/空间不足、保存关键步骤中断后重开、取消退出、结束保存退出、删除后的文件与数据库一致性。

## 包 2：识别完整性

对应：VR-08、VR-10，以及 FSMN-VAD 接入所需的模型运行子项。

前置：包 1 的可恢复音频分片和稳定时间轴。

- [ ] **FSMN-VAD 接入**：固定 ONNX 模型及运行配置，接入实际音频链路；验证前置缓冲、句尾保留、短句、连续讲话和噪声；原始音轨不受切段影响。必要的离线模型资源管理属于本包，通用在线下载器不属于。
- [ ] **静音自动暂停**：两路独立检测语音活动，均连续五分钟无语音才暂停；暂停保留浮窗，需手动继续；网络无响应不算静音。
- [ ] **云端重连与补转写**：网络失败仍持续保存音频；有界退避重连；持久记录缺失区间，从已保存音频补转写；实时字幕优先；处理重复、乱序、暂停/结束和重启后的待处理任务。
- [ ] **补齐一致性**：补转写按原时间轴合并；缺口和处理状态可见；迟到文本不能永久漏出最终纪要输入。仅做补转写所必需的现有纪要一致性处理，不扩展通用 AI 调度系统。

验收：键盘/鼠标声、轻声、两路交替讲话、五分钟静音、持续讲话、断网后恢复、去重、结束尾段及重启后补齐。使用模拟协议回归并补充真实 Paraformer 验证。

## 包 3：转写搜索

对应：VR-13 中 Transcript 搜索子项。

前置：包 2 的稳定最终 Transcript 与片段标识。

- [ ] **转写搜索**：Workspace 搜索覆盖最终 Transcript，遵守 Project / Workspace 作用域；结果定位对应 Record，避免同一 Record 产生重复命中；追加、补转写和删除后搜索结果同步。

验收：追加与补转写后搜索同步、原文保持不变、跨作用域隔离、搜索命中/定位/删除回归。

## 包 4：跨平台

对应：VR-06、VR-12 中跨屏子项。

前置：前三包的公共音频、识别与生命周期接口稳定。

- [ ] **Windows**：接入 WASAPI 麦克风与系统 loopback；对接双轨保存、FSMN-VAD、本地/云端识别、暂停/继续/结束和故障处理；验证必要的原生依赖及安装后运行。
- [ ] **跨屏浮窗**：按显示器与缩放比例保存位置；拖动、切屏、分辨率/DPI 变化和拔掉显示器后约束在可见范围；保持折叠/展开及暂停保留、结束关闭规则，不抢焦点。

验收：Windows 真实双轨采集与识别闭环；macOS / Windows 多显示器、不同 DPI、热插拔和折叠展开。

## 暂缓：短期不实施

以下事项保留历史需求，不作为当前四包的默认依赖：

- **保守润色**：引用已配置文本模型，只处理最终句或短批次；修正错字、标点、断句，不概括、不添加事实；独立保存和展示，不覆盖原始 Transcript；无模型或失败时保留原文。仅提供本功能所需的有界队列和失败隔离。 本轮挂起，不实施。
- 实时翻译及相关语言切换、历史翻译存储/恢复。
- Context Lexicon、近期 Record 提取、上下文缓存和热词增强。现有上下文开关不代表已实现该能力。
- 通用本地模型在线下载、取消、升级、多版本管理。
- 扬声器回声消除（AEC）和独立的长时漂移校正专项。
- 超长录音播放器按需加载/解码专项；包 1 只包含滚动分片必要的回放适配。
- 通用 AI 优先级、跨功能共享并发、抢占/取消调度平台，以及超出包 2 一致性需要的纪要任务重构。
- 分轨音量/静音控制、Record 移动等未列入四包的扩展体验和资产操作。
- 独立的全产品性能基准、长时压力专项、额外平台兼容与发布工程扩展。四包自身的必要测试仍须完成。

暂缓不等于删除已实现功能，也不等于验收通过。后续恢复这些事项需重新明确范围，不能直接依旧计划继续执行。
