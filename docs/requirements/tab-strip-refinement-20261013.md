# 项目与内容 Tab 视觉收敛（#124）

## 工作包

- 依赖：现有项目 / 内容 Tab、拖动和键盘交互、真实溢出测量；按用户截图统一样式。源码修改前确认无 Tauri 自动重启监听。
- 交付：两层 Tab 采用用户最终澄清的三宽度规则：下限 96px、上限 148px；当前标准宽度按视口空间和数量分摊后限定在上下限内，每个 Tab 以名称实际所需宽度（含图标 / 间距 / 控件空间）在下限与当前标准宽度之间截取。短名按下限，中间名称按自身宽度，长名称封顶到当前标准宽度，下限仍放不下时横向滚动。；内容 Tab 普通态透明、hover / 激活态浅灰圆角，仅普通相邻内容标签显示短分隔线。项目 Tab 根据用户后续纠正保留原有弧形肩部和连续选中动画，仅更新关闭按钮、遮罩和滚动条。长标题渐隐，关闭按钮仅 hover / 激活 / 键盘焦点显示，使用无圆圈的 X；显示时扩展标题遮罩，宽度与垂直布局不变。滚动条 3px、半透明、绝对定位，hover / 键盘焦点 / 拖动才显示，两层共用实现。
- 非目标：Markdown 编辑 / 保存及版本交互继续暂停；不改文件图标与其他应用打开的并行实现；不改布局存储和业务身份。
- 验收：短 / 长标题与关闭控件紧凑且不重叠；状态切换不改变 Tab 宽度或移动相邻 Tab；无溢出 / 中间 / 双边界 / 反向滚动 / 增删 / resize；横向滚轮、拖动排序 / 跨栏、键盘切换 / 关闭仍可用；减少动态效果可用。
- 验证：共享滚动条、WorkspaceTopBar、ProjectContentLayoutView 定向用例；集中 TypeScript / Vite 构建、UI 标准和 bundle 检查；集中界面验收。主 agent 自查 Standards / Spec，不启动 review 子 agent。#124 既有未完平台验收继续保留。

## 完成记录

- 实现：共用三宽度测量、标题遮罩和 X 控件样式，共用绝对定位滚动条；每个 Tab 以名称实际宽度在 96px 下限和当前标准宽度之间截取，标准宽度由可用空间 / 数量计算，并封顶到 148px。项目原弧形肩部、底部连接与移动 indicator 保留，内容使用浅灰圆角和普通邻项短线。
- 密度：外侧 padding 4px、Tab 间距 2px、内部 padding 6px、图标间距 4px；短名称距关闭命中区 2px。长标题在隐藏关闭时借用其 22px 区域，显示关闭时扩大渐隐，不改宽度；完整 Tab 留白仍支持点击 / 拖动。
