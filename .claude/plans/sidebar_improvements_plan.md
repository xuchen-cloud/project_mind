# 侧栏改进计划

## 目标
1. 修复记录 tab 的遮挡问题，使其与文件 tab 一致
2. 支持侧栏宽度拖动调整
3. 宽度自适应变化
4. 向下滚动时固定搜索和标签筛选

## 实施步骤

### 1. 修复记录项遮挡问题
**问题分析**：记录项显示了两行文本（标题 + typeLabel），可能导致内容溢出

**解决方案**：
- 移除第二行的 typeLabel 显示（已经在主页面移除，侧栏也应统一）
- 调整记录项样式，使其与文件项一致

### 2. 侧栏宽度拖动
**实现方案**：
- 添加拖动手柄在侧栏右边缘
- 使用 `useState` 存储宽度值
- 监听 `mousedown`、`mousemove`、`mouseup` 事件
- 设置最小宽度（如 200px）和最大宽度（如 480px）
- 将宽度存储到 `ui-store` 以持久化

### 3. 宽度自适应
**实现方案**：
- 小宽度（< 240px）：隐藏标签筛选
- 中宽度（240-320px）：显示基本内容
- 大宽度（> 320px）：显示完整内容

### 4. 固定搜索和标签筛选
**实现方案**：
- 将搜索框和标签筛选包装在单独的 div 中
- 使用 `sticky` 定位：`position: sticky; top: 0; z-index: 10`
- 添加背景色避免内容穿透

## 关键文件
- `src/components/layout/ProjectSidebar.tsx` - 主要实施文件
- `src/state/ui-store.ts` - 存储侧栏宽度
